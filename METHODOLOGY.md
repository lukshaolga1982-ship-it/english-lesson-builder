# Методическое ядро Smart Lesson

## 1. Основная логика урока

Генератор использует четыре характеристики логики урока иностранного языка:

1. **Целенаправленность** — каждое задание соотносится с целью урока.
2. **Целостность** — части урока соподчинены и образуют единое целое.
3. **Динамика** — задания располагаются в последовательности, соответствующей формированию навыков и развитию речевых умений.
4. **Связность** — материал един по содержанию, целевой язык проходит через упражнения, а этапы соединены вербальными связками.

## 2. Логический мостик

Между каждой парой соседних этапов требуется мостик.

Формула:

```text
результат текущего этапа
        ↓
вопрос / дефицит / новая необходимость
        ↓
следующее действие
```

Плохой вариант:

> Now let's do the next task.

Хороший вариант:

> We have identified three sources of news, but we still do not know which one people trust most. Let’s read the text and find out.

Мостик должен ссылаться на конкретный результат предыдущего задания.

## 3. Результат этапа

Для каждого этапа генерируется `stageResult` — наблюдаемый продукт работы. Например:

- список аргументов;
- 5 активизированных слов;
- заполненная таблица;
- сформулированная проблема;
- найденная информация из текста;
- короткий диалог;
- итоговое мнение группы.

Желательно, чтобы этот продукт использовался в следующем задании.

## 4. Система упражнений

Базовая траектория не является жёстким шаблоном, но генератор избегает методических скачков:

```text
осмысление / предъявление
→ контролируемая тренировка
→ условно-речевое использование
→ речевое / коммуникативное применение
```

Количество промежуточных шагов зависит от класса, уровня, знакомости материала и цели урока.

## 5. Ведущий вид речевой деятельности

Ведущая деятельность должна определять кульминационную задачу урока, а не просто присутствовать в настройках.

Примеры:

- **Диалогическая речь:** подготовка речевых средств → короткая репетиция → информационный разрыв / интервью / обмен мнениями.
- **Монологическая речь:** содержательный стимул → сбор идей → структура → подготовленное → более самостоятельное высказывание.
- **Аудирование:** установка → общее понимание → конкретная информация → использование услышанного в речи.
- **Чтение:** прогнозирование → чтение в соответствии с задачей → более глубокая работа → послетекстовая речевая задача.
- **Письмо:** коммуникативная ситуация → образец/критерии → планирование → текст → само-/взаимопроверка.

## 6. Креативное начало

Генерируются 3 разных варианта. Они должны быть **lead-in**, то есть запускать содержание урока, а не быть отдельным развлечением.

Банк включает, среди прочего:

- «Что я вижу?»;
- «Ключевой вопрос»;
- «Чёрная коробка / Коробка»;
- «Верю — не верю»;
- мем;
- шифровку;
- «Яркое пятно»;
- «Корзину идей»;
- «10×10×2»;
- «Сонастройку».

## 7. Двигательная пауза

Пауза:

- занимает примерно 1–3 минуты;
- действительно включает движение;
- не вводит сложный новый материал;
- по возможности сохраняет тематическую связь;
- для старших классов не выглядит инфантильно.

Генерируются 3 варианта. Пауза может быть отключена в настройках.

## 8. Рефлексия

Рефлексия должна возвращаться к цели и критериям успеха. Как минимум два из трёх вариантов должны давать информацию об учебном результате.

Банк включает:

- незаконченные предложения;
- рефлексивную мишень;
- «Три М»;
- «Пятёрочку»;
- сравнение ожиданий и результата;
- «Рюкзак»;
- 4 вопроса обратной связи;
- «Глупый вопрос»;
- «Пары и пальцы».

## 9. Нормативная рамка

Для V–XI классов в методическом контексте учитываются загруженные учебные программы Республики Беларусь. Они задают коммуникативную направленность, развитие видов речевой деятельности, использование разнообразных форм работы и ориентацию методов на цели и ожидаемые результаты.

Для классов, по которым отдельная программа не была загружена в проект, генератор не должен приписывать конкретные нормативные требования несуществующему источнику.
